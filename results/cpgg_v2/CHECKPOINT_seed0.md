## 실패 지점 진단

1. **메시지 신호 (가장 약함).** M-v2는 저용량 선형 + regime 상호작용으로 바꿨는데도 표본 밖 실현 ρ가 0 근처이거나 음수다(C −0.24). fold 간 계수 상관은 0.44~0.62로 계수 자체는 어느 정도 안정적이지만, 쌍별 ρ는 기록 구간과 C 사이의 상관이 +0.31에 그친다. M-v1(신경망)은 이 분할에서 더 나쁘다: Dense −68.2, 선택기와 묶어도 −61.9. 앞선 빠른 점검(`results/cpgg_quick`)에서도 target을 바꿔 봤지만 표본 밖 신호가 없었다.
2. **보정.** isotonic 보정은 거의 평평했다. 보정 후 추정 gain이 대부분 −3.4×10⁻⁴ 근처의 한 구간으로 모인다. raw 추정–실현 상관은 C에서 +0.14로 양수지만, 이는 하위 분위(큰 |d|의 손해)를 맞힌 결과다. 최상위 10분위의 실현 gain은 −1.2×10⁻³ [−3.7, +1.3]×10⁻³로 양수가 아니다. 즉 선택기는 "해로운 연결"은 구분하지만 "이로운 연결"은 찾지 못한다.
3. **임계값.** 5.2절 정의대로 c0 = placebo 95분위로 정하면 c0가 음수(−3.4×10⁻⁴)다. 대부분의 후보가 손해이기 때문이다. 그래서 주 규칙은 기대 gain이 음수인 연결도 받아들인다. c0 = max(q95, 0)이나 임계값 0을 쓰면 K가 거의 0이 되고 Own과 같아진다(−0.44 [−1.28, +0.02]).
4. **선택기 자체.** 합성 A·B·C에서는 신호가 있을 때 연결하고, 없을 때 거절했다. 같은 코드가 실제 데이터에서 연결을 거의 하지 않거나 무작위보다 나쁜 연결을 고르는 것은, 걸러낼 표본 밖 신호가 없다는 1번과 일관된다. 다만 "신호가 없다"는 증명은 아니다(통화 10개, C 1,048일, 쌍별 선형 메시지라는 한계).

## 구현 메모

- 5블록 expanding 분할과 날짜: [split_manifest.json](split_manifest.json). purge 5행. 블록 1의 자기 예측은 앞선 모델이 없어 in-sample O_1 값을 썼다(메시지 학습용 잔차에만 쓰이고, gain 기록·C에는 쓰이지 않는다).
- regime 동시 해당 시 RiskOff 우선. 합성 B의 통과 판정은 regime 집합을 주입 regime(VIX 변화 > 0)으로 둔 실행 기준이다. 실제 3-regime 실행도 참고로 함께 보고했고, 이 경우도 차이 CI 하한이 0보다 크다.
- 보정 점수에는 isotonic 동률 구간을 raw 추정으로 정렬하는 1e-7 크기의 tie-breaker를 넣었다. 첫 시험 실행에서 isotonic 평탄 구간 때문에 placebo 선택률이 0.01%로 붕괴했기 때문이다. 메시지 ridge 강도 격자도 첫 시험 실행에서 끝값(1e4)에 몰려 1e6까지 넓혔다. 두 변경 모두 합성 점검과 실제 평가 전에 했다.
- 단위 테스트 3개 통과(칸 특징 미래 누수, 채널 분해·자기쌍·placebo 일관성, 결정적 추론): `cd src && PYTHONPATH=. ../.venv/bin/python ../tests/test_cpgg_v2.py`.
- 실행: 합성 점검 약 2분, 실제 데이터 85초, 최대 메모리 1.9 GB. CPU 스레드 2개, 프로세스 1개씩 순차 실행.
